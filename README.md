# Admin Dashboard

A static admin dashboard layout (sidebar, header with search and actions, project cards, announcements and trending panels) built from a design mockup for [The Odin Project](https://www.theodinproject.com/).

## What I practiced

- Building a full app layout with **CSS Grid**: sidebar + header + content areas, with nested grids for the cards
- Flexbox for component-level alignment
- Recreating a design faithfully from a reference image

Open `index.html` in a browser.
